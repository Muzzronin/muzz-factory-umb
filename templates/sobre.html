Sobre el proyecto

Muzz Factory UMB

¿Qué es Muzz Factory UMB?

Muzz Factory UMB es una herramienta web gratuita que convierte cualquier skin de Minecraft en plantillas papercraft listas para imprimir, recortar y armar.

Nació como proyecto personal para facilitar la creación de figuras de papel de personajes de Minecraft, y hoy está disponible para toda la comunidad.

¿Cómo funciona?

  • Sube tu skin PNG (64×64 o 128×128).
  • Elige las opciones: modelo, bordes, cromas, lienzo.
  • Pulsa Generar y revisa el resultado en el panel de vista previa.
  • Descarga el PDF con las 5 páginas listas para imprimir.

Todo el procesamiento se hace en el servidor de forma temporal. Tu skin no se almacena ni se comparte con nadie.

Tecnología

El proyecto está desarrollado en Python con Flask en el backend, Pillow para el procesamiento de imágenes y ReportLab para generar los PDFs. El frontend es HTML, CSS y JavaScript puro.

¿Es gratis?

Sí, totalmente gratis. El sitio se mantiene gracias a la publicidad de Google AdSense, que permite cubrir los costes del servidor sin cobrar a los usuarios.
